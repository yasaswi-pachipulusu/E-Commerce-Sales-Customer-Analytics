# 🛒 E-Commerce Sales and Customer Analytics

## 📌 Project Overview

The **E-Commerce Sales and Customer Analytics** project focuses on analyzing e-commerce sales, customer behavior, product performance, and shipping operations using **MySQL and Microsoft Power BI**.

The objective is to transform raw business data into meaningful insights through SQL queries and interactive Power BI dashboards to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products.
- Understand customer purchasing patterns.
- Evaluate sales performance across different regions.
- Analyze shipping and delivery performance.
- Present meaningful business insights through interactive dashboards.

## 🛠️ Tools and Technologies

| Tool | Purpose |
|---|---|
| MySQL | Database management and data analysis |
| SQL | Data querying, cleaning, and analysis |
| Microsoft Power BI | Interactive dashboard creation |
| Excel / CSV | Dataset storage and preparation |

## 📊 Key Analysis Performed

1. Sales and Profit Analysis
2. Sales Performance by Region
3. Top 10 Products by Sales
4. Customer Analytics
5. Product Performance Analysis
6. Shipping Performance Analysis
